# Memory Game

Memory Game — игра на поиск пар одинаковых карточек. Нужно запомнить расположение карточек и найти все 8 пар за наименьшее число ходов.

## Деплой

[Открыть Memory Game](https://kravchuk-st.github.io/memory-game/)

## Возможности

- автоматический запуск игры при загрузке страницы;
- случайное перемешивание 16 карточек при каждой новой игре;
- подсчёт ходов и найденных пар;
- блокировка поля во время показа несовпавшей пары;
- запуск новой игры без перезагрузки страницы;
- модальное окно после победы;
- сохранение десяти лучших результатов в `localStorage`;
- таблица лидеров с количеством ходов и датой прохождения.

## Технологии

- HTML5;
- CSS3;
- JavaScript (ES-модули);
- Web Storage API.

## Локальный запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Переключитесь на ветку `memory-game`.
3. Запустите локальный HTTP-сервер. Например, в VS Code можно использовать расширение Live Server или выполнить в терминале:

```bash
   npx serve .
```

Проект использует ES-модули, поэтому открыть `index.html` двойным нажатием не получится.
